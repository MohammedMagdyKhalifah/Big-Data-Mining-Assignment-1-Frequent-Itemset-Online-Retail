How the Apriori algorithm works

The same steps are implemented in src/apriori.py and src/association_rules.py.

  1. Pass 1: count items. Keep items with count ≥ ⌈s·N⌉ → L1
  2. Join. Combine itemsets of Lk-1 sharing their first k−2 items: {A,B} + {A,C} → {A,B,C} → Ck
  3. Prune. Drop a candidate if any (k−1)-subset is not in Lk-1. It cannot be frequent (monotonicity).
  4. Count. One scan of the baskets counts the surviving candidates.
  5. Filter. Keep candidates with count ≥ ⌈s·N⌉ → Lk. Repeat until Lk is empty.
  6. Rules. For every frequent I and non-empty X ⊂ I, output X → I∖X when its confidence ≥ c.

Support

support(I) = baskets containing Iall baskets N

An itemset is frequent when support(I) ≥ s.

Confidence

conf(X → Y) = support(X ∪ Y)support(X)

Estimated P(Y | X); not symmetric.

Lift

lift(X → Y) = conf(X → Y)support(Y)

> 1: bought together more often than chance. Association, not causation.

Monotonicity

J ⊆ I ⇒ support(J) ≥ support(I)

If {A,B} is infrequent, {A,B,C} cannot be frequent, so it is pruned without counting.
